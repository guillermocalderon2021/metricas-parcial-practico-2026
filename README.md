# Examen práctico - entorno técnico

Este repositorio contiene únicamente los recursos de ejecución del escenario.
Las instrucciones, preguntas y criterios de evaluación se entregarán por separado.

## Control del escenario

```bash
./start.sh
./stop.sh
./reset.sh
```

`reset.sh` restaura el escenario inicial si fuera necesario.

## Medición del servicio

```bash
./probe.sh
```

No modifique los binarios ni los scripts del repositorio durante la evaluación.
